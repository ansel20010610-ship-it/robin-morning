# 編輯部教訓（寫手版，一條一行）

每一班寫稿前都讀這一份：每條只有規則與做法。每條出現過的位置、日期與例子在 `LESSONS.md`（稽核版，只有每週稽核讀）；稽核每加一條，就在這裡加同號、同標題的一行（`python3 scripts/lessons.py check` 會對兩份）。寫稿時避開每一條；拿不準一條的意思，再去 `LESSONS.md` 看那一條的例子。

1. **推論不可寫成事實**：學者看法、推論、自己的讀法不能夾在陳述事實的句子裡；用句子交代是誰的看法，推論段加 `tag`「推論」。寫完逐段問一次：這句是來源說的，還是我說的？
2. **著作歸屬要查到執筆者**：合編、合著的系列，要分清楚引用的是哪一冊、誰執筆。
3. **標題與導言不可誇大原文**：只出現兩次的動作不能寫成「整夜都在做」；只說「重要」的不能寫成「更重要」。
4. **二手來源要寫明是轉引**：從唱片行、宣傳頁、書評轉引的評語要寫出處與「未註明刊期與作者」；不同出處的兩段評語不可合併成一篇。
5. **自算的數字要重算**：從表格算出的極值、排名、比例，寫進正文前再算一次；抄來的數字逐位對一次。
6. **讀不到全文就不要寫細節**：只讀到摘要或部分頁面時，不寫無法核對的人數、職業、逐字引文；寫「依摘要」並標明範圍。
7. **教練說法 vs 本文推論**：記者會講的是兩件事，就不能寫成教練說了兩者的因果；連結兩者的推論要標成推論。
8. **圖解要和文字完全一致**：場形圖的站位、箭頭順序、圖說要和正文同一個情境，替代情境要明寫「不是先後發生」。
9. **「第一座／唯一／最」要查反例**：同一機構的其他文章可能說法不同，有衝突就寫出來或改用不會錯的說法。
10. **不在時間窗內的舊聞不要寫進新聞欄**；轉會傳聞要寫明是誰、哪天報的。
11. **被封鎖的網站會讓整次搜尋失敗**：WebSearch 的 `allowed_domains` 只要含一個封鎖我們的網站就回 400；不可用的網域清單見 `columns/football.md`，遇到 400 就把錯誤訊息點名的網域拿掉重搜；讀不到的來源另找可開的版本，或在 sources 註明讀了哪一份。
12. **PubMed 網頁讀不到時改用 API**：E-utilities、Europe PMC 或 Crossref（指令見 `columns/perio.md`）。
13. **請求裡不放社長的個人資料**：需要聯絡資訊的 API 一律用 `scripts/common.py` 的 `UA`（專案網址）。
14. **`updated_at` 要寫實際完稿時間，不可晚於推送時間**：推送前用 `TZ=Asia/Taipei date +%Y-%m-%dT%H:%M:00+08:00` 取當下時間填入，不估、不預填、不湊整點。
15. **圖說、credit 與背景句也是事實，要和正文一樣查**：圖說裡的日期、事件、收藏地都要能在來源找到；查不到收藏地就寫影像出處，不寫原件所在。
16. **同一個人物在文中只用一種、查證過的身分**：外文頭銜不直接譯成職業，回原文確認；兩個同性別角色接連出場時主詞寫名字，不寫「她」「他」。
17. **巴薩晨報的「查閱時間」與「尚未開賽」要從讀者打開的那一刻看**：更新時逐句找「還沒、截至、目前、留待」改成已發生的結果；查閱時間寫實際時間，不晚於刊出時間。
18. **正文提到的文獻都要列進 `sources`，日期以發布頁為準**：每位作者、年份都要在 sources 有對應；`date` 填來源的發布日期，不填事件日期；速覽每一則都要有自己的來源。
19. **摘要（brief）不可把正文標為推論的內容寫成事實**：推論與學者觀點不進摘要；寫完逐句回查正文，推論句換成一個事實。
20. **引文與說法要歸給真正說話的人，也不要替引文加上原文沒有的連接**：每句引文回原文看前後一句，確認是誰說的、在回答什麼；「因為、所以」只有原文有才寫；轉述裡自己的補充移出或刪掉。
21. **「本文推算」要用來源給的完整規則，不要只取一半**：推算或描述總譜前，把來源列的每一項條件、每個聲部列一遍再下結論。
22. **原創示範寫完要對照前文通讀一次**：分析段提到示範裡的數字、動作、台詞，都回示範原文找那一句；A／B 對照只改要比較的那一件事。
23. **轉述不可改動時間、對象或語氣，引號裡只放原句**：外文整句從原文複製，不刪字、不改寫；「隔天」「三天」不可變成「到現在」「兩三天」；限定詞不可省；引文後面緊接的轉折（but、however）要一起引；外文慣用語查辭典，不照字面拆。
24. **巴薩晨報引用的數字與「下一版補上」都要跟到最新**：引用他人統計後，若本稿已含之後的賽果就自己重算；初稿留下的「見更新版」下一班必須兌現；前一期賽程表列過的比賽，下一期要報賽果；即時數據寫明查閱時刻。
25. **備稿入庫久了，來源與「計畫、預定」會過時**：備稿班開工先抽查寫成超過一週的備稿，打開每個 sources 網址看是否仍是原機構，重查「計畫、預定、目前、唯一」等句子，有變直接改備稿本文。
26. **兩個來源各有一半的細節，不要合併後掛在其中一個名下**：每個細節標它真正的出處；從 state 檔或舊稿沿用的說法要回原頁確認現在還在，找不到就刪或寫明查閱日期。
27. **查證過程不要寫進正文，也不要拿來當標題**：「沒說、沒寫、沒交代、沒讀到、查不到、不知道、沒記」屬於作業的刪掉或移進 `sources[].note`；標題與導言寫論文發現了什麼，不寫它缺什麼；把「本報」換成「我」繼續寫作業不算改掉。
28. **研究結果的分組、強度與「只有」要對原文**：標題與導言裡的數字回原文找它屬於哪一組、哪個時間窗；「看不出差別」不寫成「沒有差別」；寫「只有、全部、都」之前數一遍；每個合併數字寫對它的分母。
29. **相對時間：寫稿前一天的「下週、前一天、今天」到刊出日都會變**：轉述別人話裡的相對時間一律換成日期；寫完逐一找「今天、昨天、前一天、下週、本週、週末」，從刊出日 07:30 重算，拿不準就寫日期。
30. **巴薩晨報的小事實要跟比賽紀錄與第二來源對**：進球、換人、黃牌從比賽紀錄（ESPN summary 的 keyEvents）抄；年齡用出生日期算；兩個來源不同時找第三個或寫日期；同名球員寫全名查一次；排名自己用同分規則排；外電初稿的星期要對當地報導；同一件事前後期說法要一致。
31. **舊規則寫的備稿要先重寫才算庫存**：`reserve.py` 列為「需修正」的（黑名單、出處類標籤、分類詞小標、缺 form／voice）先修再寫新稿；欄位規格改版後，同欄備稿一起改格式。
32. **本週新口頭禪（10-28 至 11-01，黑名單上的舊詞消失後冒出來的替代品）**：不要再用「本報」當立場標記、定時插入的「依我看」、「換我……」句型、「帳／算帳」比喻、「X 沒說」做段尾、小說欄的 A／B 模板、每段先「某某說」的來源前置句、古典欄以年份開頭的 dek 與 brief。表態用你這一篇才有的話，標推論就用 `tag`，同一個比喻這週別欄用過就不用。
33. **寫經典，先說清楚它經典在哪**：前 200 字就給一句話的答案（它讓後來的作品從此可以做什麼），每個製作細節接到觀眾感覺到的效果，懷疑的聲音放在論點之後並且要接話，結尾正面回答標題；對走進一件作品、古典欄的「為什麼值得聽」同樣適用。
34. **不要把讀者當成知道前因後果的人**：前三段交代這是誰／什麼、什麼時候、在哪裡、讀者在哪裡碰過、為什麼要講；名字第一次出現帶身分；術語一句白話；背景寫進事實清單，總編重寫才補得回來（STYLE.md 〇之三）。
35. **不在計畫裡的知識：題目要有分量，不硬扯**：選題先問「一個牙醫會不會在飯桌上轉述」，小題目要能帶出大事；不為了貼近讀者硬拿足球牙科當例子；語言學不排。
36. **每篇一種樣子，每篇一種腔**：同一欄的文體（form）每篇輪換，同一期不重複、同一欄不連用；同一欄的記者（voice）固定，不同欄彼此不同腔；審稿核對、重寫不得換（STYLE.md 〇之四、`scripts/forms.py`）；零背景優先。
37. **本週新口頭禪（11-02 至 11-08）**：不要再用段尾判決（「我信／我站／我押／我不跟／我寧可」，牙周的「我會／我不會／我的立場是」）、「依我看」「我猜」「換我」、指認句「X 說的就是這一 Y」、「把 A、B 擺在一起看」「兩邊都」、引文入口「又補一句／留了一句／接著說：」、「名作先被罵」當鉤子、收在「最後一行」並數字數、古典欄的「最有名」與「整 X 我最想讓人讀的是」、小標套版（「A：B」「X 說……」「先 A，後 B」）、「同一封信／同一章還說」當銜接。表態只留你這一篇才有、說得出代價的一兩句；引文直接放，不先「補」不先「接著」。
38. **快訊：外電說「辭職、接任」，要等它生效才寫成已發生；錯了用更正框**：辭職、下台、停火、簽署這類要程序生效的事至少兩個來源，生效前寫「提出辭呈」；發現前一期寫錯，寫稿班照常報現況並在回報裡記下，由稽核或下一班在原篇加更正框，正文不寫「本報刊出……」；轉述數字時原文的限定詞一個都不能掉。
39. **導言、摘要、正文不要是同一句**：dek 是給點進來的人的一句鉤子，brief 是首頁上只讀三句的人要知道的事，正文第一段從事實開始；寫完三處並排看，有同一個子句就刪掉其中兩處。
