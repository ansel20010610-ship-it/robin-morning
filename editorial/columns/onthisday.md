# 歷史上的今天（讀者看到的欄名：歷史上的今天；德文小標 Kalenderblatt）

日刊最下面、「近期演出」上面的一行：這一天在歷史上最有代表性的一件事，**一則訊息，不是文章**。由 06:17 的近期演出班每天順手查，寫進 `content/onthisday.json`（以當天日期為鍵，App 顯示該期自己的那一天，往期也保留）。工具是 `scripts/onthisday.py`，它會檢查格式，不合格就不寫入。

讀者：牙周病科牙醫，愛古典音樂、巴塞隆納足球隊與歐洲（尤其維也納）文化；對大多數題目毫無背景，所以這一則必須自給自足（`STYLE.md` 〇之三）。

## 選題：先列候選，再選一件

- 查英文維基百科的日期頁（`https://en.wikipedia.org/wiki/November_4` 這種）與中文版對應頁，從 Events 列出 3 到 5 個候選，再選**最有代表性**的那一件：世界史上的大事優先（戰爭的開始與結束、革命、建國、重大發明與發現、太空、醫學里程碑、重大災難、條約、經典作品的首演或出版、改變世界的人物的生卒）。
- 兩件差不多時，偏向讀者的世界：古典音樂、歐洲史、醫學與科學、足球、台灣。台灣人人都知道的日子（二二八、九二一、八二三、解嚴）也算最有代表性。
- 事件優先於生日；生卒只在人物極重要時才選（莫札特、貝多芬、達爾文這個等級）。
- 1500 年以前的事只在極著名、日期在標準參考書裡固定時才選；避免西元前。日期用現行公曆通行寫法；儒略曆時期的事件照標準參考書的通用日期，不自己換算。
- 看一下 `python3 scripts/onthisday.py show` 最近兩週選過什麼：同一個人、同一場戰爭、同一個主題不要接連出現。
- 選定後**用第二個來源查證**（Britannica、該事件的維基條目本文、官方或學術網頁）：月日、年份、人名、地點、數字都對了才寫。查不到第二個來源就換一件。

## 寫法

- 25 到 70 字，一到兩句，繁體中文（台灣用語），全形標點；數字用阿拉伯數字，與中文之間留半形空格（「1847 年」「38 歲」）；作品名用《》。
- 年份放 `--year`，正文不要以年份開頭，直接從事件講起。
- 零背景：人名第一次出現帶身分（「作曲家孟德爾頌」「英國首相邱吉爾」），地名帶國家（讀者不一定知道萊比錫在哪），術語一句白話。讀完不需要查任何東西。
- 事件本身不說明意義時，用後半句點出為什麼重要（「……，現代疫苗從此開始。」）。不寫評語，不寫「震驚世界」「意義深遠」這類空話，不用驚嘆號，不用四字成語式的標題腔。
- 不確定的數字不寫。來源用 `--source` 附網址（可以多個）。

範例：

```
python3 scripts/onthisday.py add --date 2026-11-04 --year 1922 \
  --text "英國考古學家卡特在埃及帝王谷找到圖坦卡門陵墓的第一級台階，三千多年沒人動過的法老墓就此出土。" \
  --source "https://en.wikipedia.org/wiki/Tutankhamun%27s_tomb"
python3 scripts/onthisday.py add --date 2026-12-05 --year 1791 \
  --text "作曲家莫札特在維也納過世，35 歲；未完成的《安魂曲》留在桌上，由學生接手寫完。" \
  --source "https://en.wikipedia.org/wiki/Wolfgang_Amadeus_Mozart"
```

## 每天的流程（近期演出班，近期演出做完之後）

1. `date` 確認台灣時間的今天（routine 的時鐘是 UTC，加 8 小時），日期就是今天這一期的日期。
2. 照上面選題、查證、寫入；寫入失敗就照錯誤訊息改。整件事 10 分鐘內做完，**不能拖過 07:20 的推送時限**；來不及就跳過這一天，App 那一格會空著，不會壞。
3. `content/onthisday.json` 和 `content/concerts.json`、`state/concerts/` 一起 commit 推送。commit 訊息例：「近期演出 11-05：新增 2、更新 1；歷史上的今天 1605」。
