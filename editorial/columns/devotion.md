# 今日經文與禱告（devotion）｜每日・不是文章

## 社長的規格
2026-10-31：刪掉「晨光裡的一句話」欄位，但保留 App 最上面的每日聖經節錄與今日禱告。

所以這一欄從 2026-11-01 起不再是文章：沒有標題頁、摘要、頭圖、釋義與生活連結。只寫兩樣東西：
- **今日經文**：App 最上方（報頭下）顯示它的第一節；首頁「今日禱告」展開後顯示整段。
- **今日禱告**：放在首頁報頭下方的「今日禱告」。

它照常每天要有（第 1 班寫，備稿與週日補刊規則照舊），只是 App 不把它當文章列出。

## 經文
- 1–6 節，一段完整的意思。新舊約、詩歌智慧書、福音書、書信輪替；跑 `python3 scripts/ledger.py --column devotion`，180 天內不重複同一段。
- 第一節要能單獨成句：它會一個人出現在報頭下面（太長會被截在第一個句號）。
- 用 `python3 scripts/bible.py <書卷簡稱> <章> <起節>[-<迄節>]` 從信望愛聖經工具（FHL）取和合本原文，例 `python3 scripts/bible.py 詩 23 1-3`。逐字照抄回傳內容，包括標點；不用和合本修訂版、新標點和合本或記憶中的版本。
- `version` 填 `和合本`；`source` 填 `信望愛聖經工具 FHL 和合本（bible.fhl.net），<核對日期> 核對`。

## 禱告
- 完整原創、第一人稱、直接向神說話，回應這段經文；150–300 字，結尾「奉耶穌的名禱告，阿們。」
- 誠懇的禱告語氣，不用專欄口吻，不開玩笑；不捏造讀者今天的特定經歷，不把經文變成成功或療癒的保證。
- 備稿的禱告不提特定日子或節期。

## 格式（`content/issues/<日期>/devotion.json`）
```json
{
  "column": "devotion",
  "date": "<日期>",
  "title": "<經文出處，例：詩篇 23:1–3>",
  "topic_key": "devotion:<書卷英文縮寫>-<章>-<起節>",
  "updated_at": "<實際完稿時間，含 +08:00>",
  "body": [
    { "type": "scripture", "...": "bible.py 印出的區塊整段貼上" },
    { "type": "prayer", "text": "<禱告全文>" }
  ]
}
```
不需要 `dek`、`brief`、`hero`、`sources`、小標或其他區塊；驗證只看經文與禱告（`python3 scripts/validate.py <日期> --column devotion`）。第 9 步的總編重寫與忠實度核對不適用。
