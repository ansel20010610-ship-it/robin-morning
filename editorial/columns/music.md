# 今日古典（music）｜主欄・每日

## 使用者規格
每日一篇古典樂介紹並要與 Spotify 連動，可在 App 內收聽並加入歌單。

## 選曲
- 範圍：中世紀到當代的藝術音樂；交響曲、協奏曲、室內樂、獨奏、歌劇選段、宗教音樂、藝術歌曲輪替。不要連續兩天同一作曲家或同一體裁。
- 跑 `python3 scripts/ledger.py --column music` 查已介紹過的作品。
- 可配合時令或紀念日（作曲家生日、首演週年），但要核對日期。

## 結構
1. 開頭：從作品裡一個具體可聽見的東西開始（一個動機、一個轉調、一個樂器的進場），不從作曲家生平開始。
2. `music` 區塊：作品資料與錄音。**指定一個具體錄音**（演出者、廠牌、錄音年份），並說明為什麼選它。
3. 作品背景：寫作年代、委託或首演、作曲家當時的處境——只寫能核對的。
4. 聆聽導引：逐樂章或逐段落，說「聽什麼、在哪裡」。用樂章與段落定位；**不寫秒數時間碼**，除非已用該錄音核對過。
5. 一個延伸：同一作品的另一個值得比較的錄音，或一首相關作品（只寫名稱，不做第二篇導聆）。

## Spotify
- 有 `SPOTIFY_CLIENT_ID` 與 `SPOTIFY_CLIENT_SECRET` 環境變數時，用 `python3 scripts/spotify.py search "<查詢>"` 找專輯，`python3 scripts/spotify.py album <ID>` 列出曲目，把該作品的樂章 track ID 依序填進 `tracks`，專輯 ID 填 `album`。
- 沒有憑證或查不到時，只填 `query`、`artist_hint`、`track_filter`。不可猜 ID，也不可用網路上看到但沒核對過的 ID。
- `query` 用英文或原文：作曲家姓＋作品＋演出者。

## 字數
1,800–3,000 字。

## 圖
作曲家公版肖像、手稿或初版樂譜書影、首演場地歷史圖像、與題材相關的公版畫作。圖說寫明年代與收藏。

## topic_key
`music:<作曲家姓小寫>-<作品編號或簡稱>`，例 `music:brahms-op98`。
