# 派稿單：共用頁（寫手動筆前只讀這一頁和本欄那一頁）

讀者只有一位：社長。他是牙醫師（牙周是本行）、巴薩球迷。除了這兩樣，他對題目沒有背景。
他親口說的話就是驗收標準：
「內文需要易讀性高 不可有AI感」（10-10）
「他把我當成知道前因後果的人 但我其實很多東西都是毫無概念 這樣沒有上下文他竟開始講我就完全看不懂」（11-04）
「所有欄位雖然文筆不同。但所有文章都請像是一個人類寫的」（11-06）
「所有文章可用粗體字標示重點…人事物」（11-06）
「目前所有的文章都必須要再白話文一點」（11-10）
看得懂排第一。
做法只有四條：
1. 前三段交代：這是誰／什麼、什麼時候、為什麼今天要講。第一次出場的人、機構、術語，用一句白話帶過，不要用括號塞解釋。
2. 一句只講一件事，用平常說話的詞。
3. 只寫事實清單上有的事實、數字、人名、引文。材料不夠就少寫；不補畫面、不補心理、不補因果。
4. 重點的人、事、物用粗體。
不要：給創作者的建議、查證過程的旁白、預告（「後面會講」）、段尾的總結金句。
骨架（問答、時間順序、清單……）看材料自己挑。
