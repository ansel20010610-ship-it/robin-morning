# 圖像守則

每篇都要圖文並茂：**至少一張頭圖，加上正文內至少一張圖或一個圖解**（`figure`、`timeline`、`table`、`pitch`、`svg` 都算；`detail` 不算新圖）。圖要直接服務本篇內容，不放裝飾圖。

## 不重複

- 任何一張圖片（以檔案為準，不論尺寸）只能在整份報紙出現一次。動筆前跑 `python3 scripts/ledger.py --images` 看已用過的圖。
- 同一張圖的不同裁切不算新圖。需要局部時用 `detail` 區塊。
- 原創圖解（timeline、pitch、svg）每篇重新畫，不沿用舊稿。

## 合法來源（依優先順序）

1. **Wikimedia Commons**：用 `python3 scripts/commons.py "File:檔名.jpg"` 取得縮圖網址、原始寬高、授權、作者、日期。只用 Public domain、CC0、CC BY、CC BY-SA；**credit 與 license 照實填**。不使用標示 Fair use／Non-free 的檔案。
   搜尋：`python3 scripts/commons.py --search "關鍵字"`。
2. **博物館開放資料**（作品本身是公版、且館方以 CC0 或公版釋出數位影像）：大都會博物館（Met Open Access）、芝加哥藝術博物館（AIC，IIIF）、美國國家藝廊（NGA Open Access）、荷蘭國家博物館（Rijksmuseum）、克里夫蘭美術館。填館方作品頁為 `source_url`。
3. **美國政府公版**：美國國會圖書館（LOC）的 FSA/OWI 等公版典藏、NASA、NOAA 等。
4. **原創圖解**：時間線、關係圖、場形圖、路線示意、概念表。

## 一律不用

- 新聞照片、球隊與聯賽官方照片、經紀公司照片、電影劇照（除非是公版電影的畫面且來源可核對）、遊戲官方截圖、書封。
- AI 生成或 AI「修復」的圖，任何用途都不用；不可用 AI 仿作冒充原作。
- 無法查到作者、年代、授權的圖。

## 圖說要寫清楚

- 作品：作者、題名、年代、材料、尺寸、收藏地（能查到的都寫），授權。
- 照片：拍攝者、拍攝年份、地點；現況照片要寫拍攝年份，**不把舊照當今日現況**。
- 歷史圖像：分開寫「製作年代」（`made`）與「描繪年代」（`depicts`）。例如 19 世紀畫家畫的羅馬圍城，made 是 19 世紀，depicts 是公元前。
- 公版與數位影像授權要分開查：作品公版不代表該張照片可用；以 Commons 或館方標示的影像授權為準。

## 各欄找圖方向

| 欄 | 適合的圖 |
|---|---|
| 巴薩晨報 | Commons 上當事球員、教練、球場的 CC 照片（寫明拍攝年份）；積分或賽程用 `table`；陣型用 `pitch` |
| 牙周經典 | 原創研究設計流程圖（`svg`）、結果數據表（`table`）、公版解剖或組織學插圖；論文原圖多有版權，不直接轉載 |
| 今日古典 | 作曲家公版肖像、手稿或初版樂譜、首演場地的歷史圖像、與作品題材相關的公版畫作 |
| 文明如何運作 | 公版地圖、文物照片、同時代或後世圖像（標製作／描繪年代）、`timeline`、資源流向 `svg` |
| 晨光裡的一句話 | 與經文情境相關的公版畫作或自然、地景照片；圖說寫明畫作是後世詮釋 |
| 走進一幅畫 | 作品全圖（原比例）＋ `detail` 局部；必要時加作者同時期作品比較 |
| 一格電影，一張照片 | 公版照片（如 LOC FSA/OWI）或公版電影的可核對畫面 |
| 城市的第二層 | Commons 上註明拍攝年份的街景、建築照片；歷史照片；位置示意 `svg`（註明不按比例） |
| 小說的骨架 | 原創結構示意 `svg`；若分析既有作品，可用公版插圖 |
| 一句話，讀進一本書 | 公版手稿、初版書頁、版本比較；不固定用作家肖像 |
| 看懂一段比賽 | 分步 `pitch`（必備）；可加 Commons 球場照片 |
| 咖啡館裡的思想實驗 | 概念對照 `table`、論證圖 `svg`；相關哲學家的公版肖像或原典書頁 |
| 觀測站 | 時間線、階段表；作者本人 CC 照片（Commons） |

## 核對

寫完跑 `python3 scripts/validate.py <日期> --check-urls`，確認每張圖網址可開啟、是圖片。打不開的圖就換。
